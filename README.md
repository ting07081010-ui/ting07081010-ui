# Emmanuel Chen — AI Workflow Builder for Small Education Teams

I build privacy-aware AI operations workflows for small education providers, community teams, and Traditional Chinese users.

My work focuses on turning practical AI workflows into reusable open-source building blocks: prompts, schemas, fake datasets, CLI demos, LINE bot demos, evals, and maintainer workflows.

## Current Focus

- AI operations for small tutoring schools and education teams
- Parent communication workflows
- Learner profile generation
- Teacher admin automation
- Privacy-aware handling of minors' learning data
- Traditional Chinese implementation guides for AI agents and workflow tools

## Featured Open Source Work

### [Moosie EduOps AI Kit](https://github.com/ting07081010-ui/moosie-eduops-ai-kit)

An open-source AI operations toolkit for small education providers that do not have an engineering team.

It includes:

- Reusable prompt templates
- JSON schemas for student progress, lesson records, parent messages, and tasks
- Runnable teacher-note CLI demo
- LINE webhook demo
- De-identified fake data
- Prompt quality evals
- Privacy-risk evals
- Maintainer workflows for issue triage, PR review, security review, and release notes

## Why This Matters

Many small education teams want to use AI, but they lack:

- Engineering support
- Safe data-handling patterns
- Evaluation workflows
- Reusable schemas
- Maintainer habits
- Traditional Chinese documentation

This work aims to make responsible AI workflows accessible to small schools, solo teachers, churches, nonprofits, and local community teams.

## Maintainer Principles

- No real student data in public examples
- Privacy-first workflow design
- Fake data by default
- Prompt outputs should be evaluated, not blindly trusted
- Small teams need runnable examples, not only abstract AI strategy
- Traditional Chinese users deserve implementation-grade AI documentation
